# Problem Statement
Managing student records, evaluating course marks, and calculating overall grades manually can be time-consuming and prone to human error. 

# Target Users
Academic instructors, educators, and students looking for a lightweight, fast console tool to track academic progress without needing complex spreadsheet tools.

# Scope & Key Features
- Interactive Command Line (CLI) Menu
- Dynamic Student Record Management
- Automatic Grade & Average Calculation Engine
- Local Text File Data Persistence (`students.txt`)
